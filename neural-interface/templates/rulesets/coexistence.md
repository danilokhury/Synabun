## SynaBun next to other memory or code-intelligence tools

- SynaBun owns every memory operation. Store, search, update and delete long-term context with SynaBun tools only: `remember`, `recall`, `reflect`, `forget`, `restore`, `memories`, `sync`, `category`.
- [OtherTool] is restricted to [its non-memory use, for example code search or impact analysis]. Never use it to remember, recall or reflect on past work.
- SynaBun owns page access too: for every page, public-web and localhost alike, use only the configured SynaBun browser, and open a new tab for browser work.
- Do not switch to WebSearch, WebFetch, Playwright MCP, Chrome DevTools MCP, a shell-launched or headless browser, or another web tool without an explicit user request. Playwright and Chrome DevTools belong only inside a project's automated test suite.
