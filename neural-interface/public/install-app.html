Install SynaBun as an app

The server is running in the background. Confirm installation once in your browser to give SynaBun its own app window.

Chrome or Edge: choose Install as App below, or the browser's Install app menu.

Safari on macOS: choose File → Add to Dock. Keep the name SynaBun.

SynaBun installs as an app from Chrome, Edge, or Safari on macOS. Open it in one of them to install.

After installation, reopen the native SynaBun launcher. It starts or reuses the server and opens your installed PWA. Closing the app window leaves the server running. Use Apps → Stop Server to stop it.
