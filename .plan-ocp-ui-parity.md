# Plan: OpenCode Panel UI Parity with Claude & Codex

## Goal
Bring the OpenCode panel's footer area, input area, and projectbar into visual and structural parity with the Claude Code and Codex panels — same layout language, same element positioning, same polish.

---

## Gap Analysis

| Element | Claude Panel | Codex Panel | OpenCode (current) |
|---|---|---|---|
| Projectbar | project + branch + actions | project + branch | project only |
| Input border | animated conic gradient (copper) | animated conic gradient (green) | static border on focus |
| Action controls | in header | compact in header | standalone strip above input |
| Footer left | brand + attach btn | brand link + attach btn | brand icon only |
| Footer right | Think + Plan + Auto + model | Effort + Plan + Auto + model | model dropdown + token counter |

---

## Changes

### 1 · Branch dropdown in projectbar (`ocp-panel.js` + `ocp-styles.js`)

**HTML** — add immediately after the project dropdown inside `.ocp-projectbar`:
```html
<div class="ocp-dropdown ocp-dropdown-sm" id="ocp-branch" data-placeholder="branch">
  <span class="ocp-dd-label">branch</span>
  <span class="ocp-dd-arrow">&#x25BE;</span>
  <div class="ocp-dd-menu"></div>
</div>
```

**CSS** — add `.ocp-dropdown-sm` variant (narrower):
```css
.ocp-dropdown-sm { max-width: 90px; }
```

**Logic** — add `loadBranches(path)` in `ocp-panel.js`:
- Fetches `/api/terminal/branches?path=...`
- Populates `#ocp-branch` options via the existing menu-item pattern
- Called on project-change (inside `populateProjectDropdown` option click handler)
- Called on panel show if a project is already selected
- Wire `setupDropdownToggle('#ocp-branch')` in `wireEvents()`

### 2 · Fold action bar into projectbar (`ocp-panel.js` + `ocp-styles.js`)

The standalone `.ocp-action-bar` strip (Revert / Compact / … / Share) breaks the visual flow that Claude and Codex don't have. Fix: remove it and migrate the three buttons into the projectbar row as icon-only buttons pushed to the right.

**HTML** — new `.ocp-projectbar`:
```html
<div class="ocp-projectbar">
  <div class="ocp-dropdown" id="ocp-project-dd" data-placeholder="project...">...</div>
  <div class="ocp-dropdown ocp-dropdown-sm" id="ocp-branch" data-placeholder="branch">...</div>
  <span style="flex:1"></span>
  <div class="ocp-bar-actions">
    <button class="ocp-bar-btn" id="ocp-revert" title="Revert last turn" disabled>ICON_REVERT</button>
    <button class="ocp-bar-btn" id="ocp-compact" title="Compact context" disabled>ICON_COMPACT</button>
    <button class="ocp-bar-btn" id="ocp-share" title="Share session" disabled>ICON_SHARE</button>
  </div>
</div>
```

Remove `<div class="ocp-action-bar" id="ocp-action-bar">` from DOM entirely.

**CSS** — new classes:
```css
.ocp-bar-actions { display: flex; align-items: center; gap: 2px; }
.ocp-bar-btn {
  width: 22px; height: 22px; border: none; border-radius: 5px;
  display: inline-flex; align-items: center; justify-content: center;
  background: transparent; color: rgba(255,255,255,0.25);
  cursor: pointer; transition: all 0.15s;

.ocp-bar-btn:hover:not(:disabled) { background: rgba(255,255,255,0.06); color: rgba(255,255,255,0.55); }

.ocp-bar-btn svg { width: 11px; height: 11px; stroke: currentColor; fill: none; stroke-width: 2; }
```

Remove `.ocp-action-bar` and `.ocp-action-btn` CSS rules.

`syncActionBar()` uses `panelEl('#ocp-revert')` etc. by ID — IDs are preserved, no logic changes needed.

### 3 · Animated conic gradient input border (`ocp-styles.js`)

Mirror the exact pattern used in Claude and Codex — `@property` + `::before` mask trick — using OCP's warm cream accent `#E8E0DC`.

**Add/replace in CSS:**
```css
@property --ocp-input-angle {
  syntax: '<angle>';
  initial-value: 0deg;
  inherits: false;
}
@keyframes ocp-input-spin {
  to { --ocp-input-angle: 360deg; }
}

.ocp-input-shell {
  position: relative;
  display: flex; align-items: flex-end;
  border-radius: 10px;
  padding: 1px;
  background: rgba(255,255,255,0.04);
  transition: background 0.4s;
  overflow: hidden;
}
.ocp-input-shell::before {
  content: '';
  position: absolute; inset: 0;
  border-radius: 10px;
  padding: 1px;
  background: conic-gradient(
    from var(--ocp-input-angle),
    rgba(232,224,220,0.0) 0%,
    rgba(232,224,220,0.55) 25%,
    rgba(232,224,220,0.08) 50%,
    rgba(232,224,220,0.55) 75%,
    rgba(232,224,220,0.0) 100%
  );
  -webkit-mask: linear-gradient(#fff 0 0) content-box, linear-gradient(#fff 0 0);
  -webkit-mask-composite: xor;
  mask: linear-gradient(#fff 0 0) content-box, linear-gradient(#fff 0 0);
  mask-composite: exclude;
  opacity: 0;
  transition: opacity 0.4s;
  pointer-events: none;
}
.ocp-input-shell:focus-within::before {
  opacity: 1;
  animation: ocp-input-spin 3s linear infinite;
}
.ocp-input-shell:focus-within {
  background: rgba(232,224,220,0.03);
  box-shadow: 0 0 20px rgba(232,224,220,0.04), 0 0 60px rgba(232,224,220,0.015);
}
```

Remove the old `border: 1px solid rgba(255,255,255,0.06)` and `border-color` focus transition from `.ocp-input-shell`.

The inner `.ocp-input` and `.ocp-send` layout is unchanged — they sit on top of the `::before` layer.

### 4 · Footer toolbar polish (`ocp-panel.js` + `ocp-styles.js`)

Minor tweaks to align footer left with the Claude/Codex visual weight:

- **Brand icon** → wrap in `<a>` tag linking to `https://opencode.ai` (opens new tab), `title="OpenCode"`, matching Codex's `cxp-brand-link` pattern.
- **Footer padding** → `.ocp-footer-toolbar` padding from `4px 10px 8px` → `4px 10px 6px` (tighter, matching codex cadence).
- **Footer left gap** → confirm `gap: 6px` (currently `4px` — bump to match `cp-toolbar-left`).

## Files Changed

| File | What changes |
|---|---|
| `ocp/ocp-panel.js` | Branch dropdown HTML, fold action-bar into projectbar, brand `<a>` link, `loadBranches()` fn, wire `#ocp-branch` toggle |
| `ocp/ocp-styles.js` | `.ocp-dropdown-sm`, `.ocp-bar-btn`, animated border CSS (`@property`, `::before`, `@keyframes`), footer padding/gap tweaks, remove old `.ocp-action-bar`/`.ocp-action-btn` rules |

No changes to `ocp-tabs.js`, `ocp-render.js`, `ocp-ws.js`, or `ocp-icons.js`.

---

## What Does NOT Change

- All existing element IDs are preserved — `syncActionBar()` and other JS logic needs zero updates.
- No Codex-specific toggles (Effort/Plan/Auto) are added to OCP.
- The header, tab pills, messages area, and panel shell are untouched.
