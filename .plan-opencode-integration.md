# OpenCode Full Integration Plan

## Overview

Transform the raw OpenCode Settings page into a full-featured provider management, authentication, and configuration UI — and sync the sidepanel model dropdown with live provider/auth state.

**Scope**: Full auth flows (API key + OAuth + Zen/Go), all config sections (model/agent, compaction/share, MCP, permissions/tools), sidepanel model sync with auth-aware filtering.

**Files touched**: `server.js`, `ui-settings.js`, `ocp-tabs.js`, `ocp-panel.js`

---

## Phase 1: Server-Side — New Proxy Endpoints

**File**: `neural-interface/server.js` (after existing opencode endpoints, ~line 3647)

Add these REST endpoints that proxy to OpenCode's HTTP API:

| New Endpoint | Proxies To | Purpose |
|---|---|---|
| `GET /api/opencode/providers/auth` | `GET /provider/auth` | Get auth methods per provider (api_key, oauth, etc.) |
| `PUT /api/opencode/auth/:providerId` | `PUT /auth/:providerId` | Set API key / credential for a provider |
| `GET /api/opencode/providers/full` | `GET /provider` | Full provider response with `connected[]` array |
| `POST /api/opencode/oauth/:providerId/authorize` | `POST /provider/:id/oauth/authorize` | Start OAuth flow (returns URL + code) |
| `POST /api/opencode/oauth/:providerId/callback` | `POST /provider/:id/oauth/callback` | Handle OAuth callback |
| `GET /api/opencode/agents` | `GET /agent` | List available agents |
| `GET /api/opencode/config/providers` | `GET /config/providers` | Providers with default model mappings |
| `GET /api/opencode/mcp` | `GET /mcp` | List MCP server statuses |
| `POST /api/opencode/mcp` | `POST /mcp` | Add MCP server dynamically |
| `GET /api/opencode/tools` | `GET /experimental/tool/ids` | List available tool IDs |
| `POST /api/opencode/config/reveal` | N/A (shell open) | Open config directory in OS file manager |

Also add these WS message types to `handleOpencodeWs()`:

| WS Type | Proxy | Purpose |
|---|---|---|
| `providers:full` | `GET /provider` | Full provider data with `connected[]` |
| `providers:auth` | `GET /provider/auth` | Auth methods per provider |
| `auth:set` | `PUT /auth/:id` | Set API key |
| `oauth:authorize` | `POST /provider/:id/oauth/authorize` | Start OAuth |
| `oauth:callback` | `POST /provider/:id/oauth/callback` | OAuth callback |
| `agents:list` | `GET /agent` | List agents |
| `config:providers` | `GET /config/providers` | Providers + defaults |
| `mcp:list` | `GET /mcp` | MCP servers |
| `mcp:add` | `POST /mcp` | Add MCP server |
| `tools:list` | `GET /experimental/tool/ids` | Tool IDs |

## Phase 2: Settings UI — Provider Authentication

**File**: `neural-interface/public/shared/ui-settings.js`

### 2A: Redesign Provider List (replace raw dump)

Replace the current flat provider list with interactive provider cards:

```
┌─────────────────────────────────────────────┐
│ ● Anthropic                    ✅ Connected  │
│   claude-opus-4-6, claude-sonnet-4-6, +4    │
│   [Disconnect]                               │
├─────────────────────────────────────────────┤
│ ○ OpenAI                       ○ Not set     │
│   gpt-5.4, gpt-5.3-codex, +12              │
│   Auth: [Enter API Key] [ChatGPT Plus/Pro]  │
├─────────────────────────────────────────────┤
│ ○ GitHub Copilot               ○ Not set     │
│   [Login with GitHub →]                      │
├─────────────────────────────────────────────┤
│ ● OpenCode Zen                 ✅ Connected  │
│   35 models — claude, gpt, gemini, +more    │
│   [Disconnect]                               │
└─────────────────────────────────────────────┘
```

Each provider card shows:
- **Name** + model count
- **Connection status badge**: green dot + "Connected" / dim dot + "Not set"
- **Auth actions** based on `GET /provider/auth` response:
  - `type: "api"` → "Enter API Key" button that expands inline input
  - `type: "oauth"` → "Login with [Provider] →" button that starts OAuth
  - Multiple methods → show all options (e.g., Anthropic: "Claude Pro/Max" OAuth + "Enter API Key")
- **Model list** (collapsed, expandable on click) showing available models
- **Connected** state derived from `GET /provider` response's `connected[]` array

### 2B: API Key Entry Flow

When user clicks "Enter API Key" on a provider:
1. Expand inline input field with `type="password"` + eye toggle for visibility
2. "Save" button calls `PUT /api/opencode/auth/:providerId` with `{ type: "api", key: "..." }`
3. On success: refresh provider list, update status badge to "Connected", collapse input
4. On error: show inline error message below input

### 2C: OAuth Flow

When user clicks an OAuth button (e.g., "Login with GitHub", "Claude Pro/Max"):
1. Call `POST /api/opencode/oauth/:providerId/authorize`
2. Response contains `{ url, code? }` — URL to open + optional device code
3. Open URL via `window.open()` (new tab) or SynaBun browser panel
4. For device-code flows (GitHub Copilot): show the code in a highlighted badge for user to enter
5. Show "Waiting for authorization..." spinner
6. Poll provider status every 2s until `connected[]` includes the provider, then refresh

### 2D: OpenCode Zen/Go Account Connection

Special highlighted card at the top of the provider list:
- OpenCode branding + "Zen" label
- "Connect to OpenCode Zen" button → opens `https://opencode.ai/auth` in new tab
- Instruction text: "Create an account, add billing, copy your API key"
- API key paste input → `PUT /auth/opencode { type: "api", key: "..." }`
- On connect: show Zen model count + "Connected" badge

## Phase 5: Sidepanel Model Dropdown — Auth-Aware Sync

**File**: `neural-interface/public/shared/ocp/ocp-tabs.js`

### 5A: Enhanced `loadProviders()`

Change from basic `providers:list` to `providers:full` WS message which returns:
```json
{
  "all": [...providers with models...],
  "default": { "anthropic": "claude-sonnet-4-6" },
  "connected": ["anthropic", "opencode", "openai"]
}
```

Store `_connectedProviders = new Set(resp.data.connected)` alongside `_providers`.

### 5B: Auth-Aware `populateModelDropdown()`

Update dropdown rendering in `populateModelDropdown()`:
- **Connected providers**: normal styling, full opacity, clickable
- **Disconnected providers**: 40% opacity group label + "(not connected)" suffix + lock icon
- Clicking a disconnected provider's model → show toast: "Connect [Provider] in Settings first"
- Clicking a connected model → works as before (sets tab model, saves to localStorage)

### 5C: Live Refresh on Settings Change

When provider auth state changes in Settings:
- After successful `PUT /auth/:id` or OAuth completion → dispatch `CustomEvent('ocp-providers-changed')` on `document`
- `ocp-panel.js` listens for this event → calls `loadProviders()` + `populateModelDropdown()`
- No page reload needed — instant reflection of new auth state

## Key OpenCode API Reference

| Endpoint | Method | Purpose |
|---|---|---|
| `/provider` | GET | All providers + `connected[]` + `default{}` |
| `/provider/auth` | GET | Auth methods per provider (`{ [id]: AuthMethod[] }`) |
| `/provider/:id/oauth/authorize` | POST | Start OAuth → `{ url, code? }` |
| `/provider/:id/oauth/callback` | POST | Complete OAuth callback |
| `/auth/:id` | PUT | Set credentials: `{ type: "api", key: "..." }` |
| `/config` | GET/PATCH | Read/write full config (model, agent, compaction, share, permissions, tools) |
| `/config/providers` | GET | Providers with default model mappings |
| `/agent` | GET | List available agents |
| `/mcp` | GET/POST | List MCP servers / add new one |
| `/experimental/tool/ids` | GET | List all tool IDs |
