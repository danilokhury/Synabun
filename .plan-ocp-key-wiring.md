# Plan: Fix OpenCode API Key Wiring + Model Dropdown Search

## Assessment Summary

### Bug 1: API Keys Not Activating Providers

**Root cause confirmed via live testing:**

- `~/.local/share/opencode/auth.json` — keys for `zai`, `anthropic`, `cohere` ARE being saved correctly
- `GET /provider` → `connected: ['opencode']` only — even after `PUT /auth/zai` with a real key
- OpenCode PID 4179 launched at 12:16 — its process.env has **zero provider API keys**
- `PUT /auth/:id` returns `true` and writes to auth.json, but the **running process does not reload auth.json dynamically**
- OpenCode Zen is connected because it has `"options": { "apiKey": "public" }` — no user key needed

**Conclusion**: OpenCode reads `auth.json` at **startup** to determine connected providers. Writing via `PUT /auth/:id` while the server is running does nothing to the in-memory state. A restart is required. Currently the server is `managed: false` (external process — `_ocpProc = null`), so SynaBun can't auto-restart it.

**Current broken chain:**
1. User adds key → `PUT /auth/:id` → auth.json updated ✓
2. `refreshOcpProviders()` called → `GET /provider` → still `connected: ['opencode']` ✗
3. `ocp-providers-changed` event fired → panel reloads providers → still disconnected ✗

**Chain after fix:**
1. User adds key → `PUT /auth/:id` → auth.json updated ✓
2. If managed: auto-restart OpenCode → picks up auth.json at startup → `connected` updates ✓
3. If external: show clear "restart required" banner with command ✓

---

### Bug 2: Model Dropdown Has No Search/Filter

`populateModelDropdown()` in `ocp-tabs.js` renders 109 providers × hundreds of models as a plain scrolling list. No search input, no filter capability.

## Implementation Plan

### Fix 1: server.js — `PUT /api/opencode/auth/:providerId` (~20 lines)

**File:** `neural-interface/server.js`
**Line:** ~3741

```js
// BEFORE:
app.put('/api/opencode/auth/:providerId', async (req, res) => {
  try {
    if (!_ocpReady) return res.status(503).json({ ok: false, error: 'OpenCode server not running' });
    const r = await ocpProxy('PUT', `/auth/${req.params.providerId}`, req.body);
    res.status(r.status).json({ ok: r.status === 200, data: r.data });
  } catch (err) {
    res.status(500).json({ ok: false, error: err.message });
  }
});
```

```js
// AFTER:
app.put('/api/opencode/auth/:providerId', async (req, res) => {
  try {
    if (!_ocpReady) return res.status(503).json({ ok: false, error: 'OpenCode server not running' });
    const r = await ocpProxy('PUT', `/auth/${req.params.providerId}`, req.body);
    if (r.status === 200 && _ocpProc) {
      // Managed server: schedule restart so new credentials are loaded from auth.json
      setTimeout(async () => {
        stopOpencodeServer();
        await new Promise(resolve => setTimeout(resolve, 1000));
        await ensureOpencodeServer();
      }, 300);
    }
    res.status(r.status).json({ ok: r.status === 200, data: r.data, needsRestart: !_ocpProc });
  } catch (err) {
    res.status(500).json({ ok: false, error: err.message });
  }
});
```

### Fix 3: ocp-tabs.js — search input in model dropdown (~35 lines)

**File:** `neural-interface/public/shared/ocp/ocp-tabs.js`
**Function:** `populateModelDropdown()`, line 439

After `menu.innerHTML = ''`, prepend a search input:
```js
const searchInput = document.createElement('input');
searchInput.className = 'ocp-model-search';
searchInput.placeholder = 'Search models…';
searchInput.setAttribute('autocomplete', 'off');
// prevent dropdown close on click inside search
searchInput.addEventListener('mousedown', e => e.stopPropagation());
menu.appendChild(searchInput);
```

After all groups are appended, wire the filter logic:
```js
searchInput.addEventListener('input', () => {
  const term = searchInput.value.toLowerCase();
  let prevLabel = null;
  let prevLabelVisible = false;
  for (const el of menu.children) {
    if (el.classList.contains('ocp-dd-group-label')) {
      if (prevLabel) prevLabel.style.display = prevLabelVisible ? '' : 'none';
      prevLabel = el;
      prevLabelVisible = false;
    } else if (el.classList.contains('ocp-dd-option')) {
      const match = !term || el.textContent.toLowerCase().includes(term);
      el.style.display = match ? '' : 'none';
      if (match) prevLabelVisible = true;
    } else if (el.classList.contains('ocp-dd-sep')) {
      el.style.display = prevLabelVisible ? '' : 'none';
      if (prevLabel) prevLabel.style.display = prevLabelVisible ? '' : 'none';
      prevLabel = null; prevLabelVisible = false;
    }
  }
  if (prevLabel) prevLabel.style.display = prevLabelVisible ? '' : 'none';
});
```

Auto-focus on dropdown open: in the existing `.ocp-dd-toggle` click handler in `ocp-panel.js`, after `menu.classList.toggle('open')`, add `if (menu.classList.contains('open')) menu.querySelector('.ocp-model-search')?.focus()`.
